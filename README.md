# Career incentives make Registered Reports unattractive under realistic academic conditions

### Abstract
Registered Reports are a publication format designed to reduce publication bias by guaranteeing publication before results are known. This guarantee is considered attractive in the prevailing 'publish or perish' culture. But would researchers always prefer such a low-risk option? When strong results allow publication in prestigious journals, the results-dependent nature of standard publications can actually be an advantage for authors. Given this trade-off, the choice between publication formats represents decision making under risk, and researchers may not always be risk-averse. To better understand under which circumstances Registered Reports are likely to be popular, we draw on risk-sensitivity theory from behavioural ecology and develop an agent-based model that explores how four factors shape publication strategies: whether additional publications yield diminishing or increasing career returns, the pace at which studies are completed, publication targets, and competition. We find that many realistic configurations lead researchers to avoid Registered Reports, even when Registered Reports are nearly as valuable as the best possible standard publication. Intense competition and low empirical pace can make the format unviable, while high empirical pace attenuates most other effects. Given prevailing career incentives in many fields, these results suggest that the market share of Registered Reports may remain trivially low without additional incentives or interventions.

### Content of the repository
This repository contains all code to reproduce the simulations and figures in this study, as well as the data generated by the simulations to allow for simpler and faster reproduction of the figures and the manuscript itself. 

* **Appendix**: The folder [`appendix/`](http://github.com/amscheel/rr-model/tree/master/appendix) contains 
    + the [Appendix document](https://github.com/amscheel/rr-model/blob/master/appendix/rr-risk-sensitivity_appendix.pdf) with additional figures and the results generated by an alternative, non-evolutionary model
    + the [RMarkdown code](https://github.com/amscheel/rr-model/blob/master/appendix/rr-risk-sensitivity_appendix.Rmd) used to produce the document
* **Code**: The folder [`code/`](https://github.com/amscheel/rr-model/tree/master/code) contains the following scripts:
    + `03_evo-model_execute.R` is the primary script for reproducing the evolutionary agent-based model reported in the manuscript and contains the code for all specific model configurations. It relies on functions provided in the scripts `01_evo-model_main-function.R` and `02_evo-model_helper-functions.R`. 
    + `07_EF-model_execute.R` is the primary script for reproducing the alternative, non-evolutionary model reported in the appendix. It relies on function provided in the script `06_EF-model_function.R`.
    + `04_plot_fitnesscurves.R` generates **Figure 1** in the manuscript. (Note that there is no script for **Figure 2** because this figure is generated via code embedded in the manuscript.)
    + `05-a_plot_evo.R` contains code to simulate the data presented in **Figure 3** in the manuscript, as well as the code for generating the figure itself. It relies on functions provided in `02_evo-model_helper-functions.R`.
    + Scripts `05-b_*.R` through `05-e_*.R` generate **Figures 4--7** in the manuscript. These scripts rely on data generated by the evolutionary simulation model that are provided in the `data/` folder (see below).
    + Scripts `08-a_*.R` through `08-c_*.R` generate **Figures A1--A3** in the Appendix. These scripts rely on data generated by the alternative, non-evolutionary simulation model that are provided in the `data/` folder (see below).
    + `09_plot_gamma_evo_line.R` generates **Figure A4** in the Appendix, which is an alternative version of Figure 7 in the manuscript. It relies on the same data as Figure 7, also provided in the `data/` folder (see below).
    + `plot_variance_for-slides.R` generates an alternative version of Figure 2 with larger font size.
* **Data**: The folder [`data/`](https://github.com/amscheel/rr-model/tree/master/data) contains all simulated datasets:
    + `simdata_evo_summary_forplotting.RData` contains the data presented in **Figure 3** (generated by code provided in `05-a_plot_evo.R`).
    + The remaining '`evo`' datasets contain the data presented in **Figures 4--7** in the manuscript and in **Figure A4** in the Appendix (generated by code provided in `03_evo-model_execute.R`).
    + The three '`EF`' datasets contain the data presented in **Figures A1--A3** in the Appendix (generated by code provided in `07_EF-model_execute.R`).
* **Plots**: The folder [`plots/`](https://github.com/amscheel/rr-model/tree/master/plots) contains the files for Figures 1--7 in the manuscript and Figures A1--A4 in the Appendix (generated by code in the [`code/`](https://github.com/amscheel/rr-model/tree/master/code) folder).
* **Preprint**: The folder [`preprint/`](https://github.com/amscheel/rr-model/tree/master/preprint) contains the [bioRxiv preprint](https://www.biorxiv.org/content/10.64898/2026.07.17.739248v1) as a [PDF document](https://github.com/amscheel/rr-model/blob/master/preprint/rr-risk-sensitivity_preprint_v1.pdf) and the [RMarkdown code](https://github.com/amscheel/rr-model/blob/master/preprint/rr-risk-sensitivity_preprint.Rmd) used to produce the preprint, along with two .bib files and several auxiliary files.
* **Submission**: The folder [`submission/`](https://github.com/amscheel/rr-model/tree/master/submission) contains the documents of our journal submissions.

### Usage
In order to reproduce the simulations or try alternative model settings, we recommend downloading the entire repository and accessing it via the included [`rr_model.RProj`](https://github.com/amscheel/rr-model/blob/master/rr-model.Rproj) file.
